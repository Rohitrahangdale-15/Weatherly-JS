# 🌦️ Weatherly JS – Weather Forecast Application

**Weatherly JS** is a responsive weather application built using HTML, CSS, Bootstrap, and JavaScript. It uses the OpenWeatherMap API to fetch and display real-time weather information for different cities around the world.

## 🚀 Live Features

- 🔍 Search weather by city name.
- 🌡️ Display current temperature.
- 📊 Show minimum and maximum temperature.
- 💧 Display humidity percentage.
- 🌬️ Show wind speed.
- 🌡️ Display atmospheric pressure.
- 🌤️ Dynamic background images based on weather conditions.
- 📱 Responsive design for desktop, tablet, and mobile devices.
- ⚡ Real-time weather data using OpenWeatherMap API.

## 🛠️ Technologies Used

## ⚙️ How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/Rohitrahangdale-15/Weatherly-JS.git
```

2. Open the project folder in VS Code.

3. Configure your OpenWeatherMap API key in the local configuration expected by the application.

4. Start the application using the Live Server extension in VS Code.

5. Search for any city and explore its weather information.

## 🔑 API Used

**OpenWeatherMap API**

This application uses the OpenWeatherMap Current Weather Data API to retrieve weather information.

Website: https://openweathermap.org/api

**Note:** You need your own API key to run the application. Never upload your private API key to a public GitHub repository.
